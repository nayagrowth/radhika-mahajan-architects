# Radhika Mahajan Architects (RMA) — Official Studio Website

Official website and digital presence for **Radhika Mahajan Architects (RMA)** / **Radhika Mahajan (OPC) Private Limited**, led by Founder & Principal Architect **Ar. Radhika Mahajan**.

## Brand Formula
FORM × SPACE × DETAIL

## Core Services
- Full Home Turnkey Interiors (3 & 4 BHK)
- Architectural Planning & Custom Villas (Pune & Lonavala)
- Modular Kitchens & Wardrobe Joinery (Hettich / Ebco)
- Complete Civil Remodeling & Turnkey Project Management

## Tech Stack
- **Framework**: Next.js (App Router, Standalone Output) + React 19 + TypeScript
- **Styling**: Vanilla CSS Modules with brand design tokens
- **Animations**: GSAP 3.15 + ScrollTrigger pinned editorial sequence
- **Container**: Docker + Traefik TLS
- **Deployment**: GitHub Actions CI/CD to NayaGrowth preview infrastructure (
ma.preview.nayagrowth.com)
